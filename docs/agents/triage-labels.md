# 分诊标签

各技能以五个标准分诊角色来表述。本文件把这些角色映射到本仓库问题跟踪器中实际使用的标签字符串。

| mattpocock/skills 中的标签 | 本仓库的标签 | 含义 |
| -------------------------- | ------------ | ---- |
| `needs-triage`             | `needs-triage`     | 需维护者评估该 issue |
| `needs-info`               | `needs-info`       | 等待报告者补充信息 |
| `ready-for-agent`          | `ready-for-agent`  | 已充分明确，可交给 AFK agent |
| `ready-for-human`          | `ready-for-human`  | 需要人工实现 |
| `wontfix`                  | `wontfix`          | 不予处理 |

当技能提到某个角色（例如「打上 AFK-ready 分诊标签」），使用上表中对应的标签字符串。

如需调整词汇，编辑「本仓库的标签」一列即可。
